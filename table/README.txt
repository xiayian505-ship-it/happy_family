shift_roster_v1｜櫃檯人員排班紀錄表

這是一份完全獨立的前端開發版。
不使用 CDN、不依賴外部套件；HTML / CSS / JS 放在同一資料夾即可使用。

檔案：
- shift_roster_v1.html：頁面骨架
- shift_roster_v1.css：畫面 / 手機自適應 / A4 橫式列印
- shift_roster_v1.js：排班輸入、模式、對話框、月份畫面狀態
- shift_roster_storage.js：localStorage、月份 key、人員 ID、月份資料讀寫
- shift_roster_backup.js：JSON 下載 / 匯入 / 格式驗證 / 歷史月份清理
- shift_roster_rules.js：規則檢查（含跨月連勤、跨月轉班）
- shift_roster_export.js：原生 Canvas 繪製 → PNG → 預覽 / 下載 / 列印

本機資料 key：
- elitehotel:shift_roster:meta
- elitehotel:shift_roster:settings
- elitehotel:shift_roster:employees
- elitehotel:shift_roster:month:YYYY-MM

目前主要功能：
1. 開啟時依裝置本機日期預設顯示「下個月」；年月可自由切換並自動跨年。
2. 每月份獨立保存；新月份第一次建立時沿用相鄰月份的人員姓名、employee ID 與人員班別，排班／排休內容保持空白。
3. A~F 是當月班表位置，不是永久人員 ID；跨月規則使用固定 employee ID 辨認同一人。
4. 姓名直接在班表輸入；輸入即保存，離開姓名格 / Enter 後確認 employee ID。姓名身分比對忽略空白，畫面仍保留原輸入格式。
5. 五個班別的上下班時間可在「說明 → 編輯基本值」修改；早／中／夜分類固定。
6. 日期列維持兩白兩灰跨月連續；六日粉紅。
7. 預設禁休星期可在說明頁複選；班表上的「禁休」按鈕只處理單日例外。禁休限制假別可選公休／特休，請假不受禁休阻擋。
8. 第四列夜班於週六仍固定預設灰底，避免漏標；其他灰底可逐格手動套用／取消。
9. 粉底、灰底的實際時間都可留空：沒填時沿用原班時間（第四列週六預設灰底沿用灰底預設時間）；有填時用實際時間參與轉班檢查並在長條註記。只填單邊時間會提醒。
10. 粉底／灰底再點已變色格會直接取消，並清掉該格自訂時間。
11. 假別固定四類：公休、特休、請假、例外排休。請假可選填「病假／事假／公假／婚假／喪假／其他」備註；長條顯示實際假別文字。
12. 特休數字完全人工輸入，不自動增加、歸零、扣除或跨月帶值。若本月第一次設定某人特休，且同一 employee ID 上月曾排特休，會提醒確認本月特休天數；同一人同月只提醒一次。
13. 開會：點日期長條加入／取消開會備註；預設文字為「8點櫃檯開會」，可在說明頁修改。新加入的開會會保存當下預設文字。
14. 新增「備註」模式：點日期長條可輸入最多 10 字自由備註，不會取代系統產生的時間／假別／開會註記。
15. 每天休假欄仍固定兩格以維持 A4；若兩格都滿，可在「備註」模式登記第三人休假。第三人休假是結構化資料，會正常參與排假、同組、相鄰與跨月連勤等檢查。
16. 點班別標題可整列填 A~F，之後仍可逐格修改。
17. 點下方姓名區 A~F 可批次排公休；批次最大天數直接跟「每月公休目標」共用同一設定，不再另寫固定 8 天。兩格已滿、已排班或已有其他假別的日期會略過並列出。
18. 排班與休假互斥；衝突時由使用者選「排班 / 休假」，系統不自行覆蓋。
19. 人員班別為每月資料，可複選早班／中班／夜班；新月可沿用上月，但之後可獨立修改。
20. 同日排休規則可啟用／停用；分組方式可選：早｜中｜夜、早中｜夜（預設）、早夜｜中、早｜中夜、早中夜全部同組；每組同日最多排休人數可設定。
21. 「中班休 → 隔天早班休」相鄰排休提醒可啟用／停用；規則本身仍固定，不做任意組合編輯器。
22. 每月公休目標可修改但不可停用；連續上班上限可修改但不提供停用。
23. 轉班最低間隔可修改，也可啟用／停用。粉／灰底有實際時間時會使用實際時間計算。
24. 排假檢查看的是「公休目標」而非總休假天數：例如 8 公休＋1 特休正常；若 9 天都仍標成公休，會提醒是否忘記設定特休／請假。
25. 規則檢查仍包含資料完整性提醒：有效員工未設定人員班別、前月銜接資料不存在／不足、已輸入時間格式無效等。這些不是公司制度開關，不會因規則停用而消失。
26. 跨月規則依 employee ID 判斷，不按 A~F。連勤往前讀前月月底；轉班啟用時也會比較前月最後一班與本月第一班。
27. 本月清空保留姓名與公休／特休數字，其餘當月排班、假別、標記、備註、第三人休假等資料清除。
28. 列印／匯出 PNG 前詢問是否加入右上角時間。
29. PNG 使用原生 Canvas；檔名為 EliteHotel_YYYYMMDD_HHmm.png。
30. A4 橫式固定；現階段列印安全邊界仍為 6mm，古董印表機 12mm 安全邊界尚未處理。
31. 全部使用系統安全字體 fallback，不外連字體。

JSON 備份
--------
- 下載檔名：EliteHotel_YYYYMMDD_HHmm.json。
- JSON 為完整備份：包含 schemaVersion、全域設定、員工 ID 與所有已保存月份。
- 月份資料包含假別備註、自由備註、第三人休假、開會文字與特休提醒狀態。
- 匯入前先解析並完整驗證格式；格式錯誤時不修改現有資料。
- 格式驗證成功後才顯示覆蓋警告，提供「取消 / 確認匯入」。
- 確認匯入後整包覆蓋，不做資料合併；提交失敗時嘗試回復原資料。
- 「進階資料管理」可手動清除指定月份以前的歷史資料；不做自動刪除。

本機保存注意：
- 一般使用自動寫入 localStorage，不需另按儲存。
- 若瀏覽器無法使用 localStorage，程式會警告；該次仍可操作，但重新整理可能失去資料，建議下載 JSON。
- 本機資料不保存 PNG、圖片、Blob 或其他大型檔案，主要為純文字 / 數字 / 布林資料。
- 正式公司版預計在功能凍結後由拆檔開發版合併成單一 HTML；目前仍維持拆檔方便測試與維護。
