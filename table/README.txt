shift_roster_v1

櫃檯人員排班紀錄表｜HTML / CSS / JS 分檔版

功能：
- 可切換年份、月份，自動生成當月 28～31 天。
- 上方日期底色依「兩白、兩黑」連續循環，跨月份不中斷。
- 星期六、星期日另有灰階標示。
- 五個班別的每日格子只能輸入 1 個英文字母。
- 「休假」每一天保留上下兩格，各可輸入 1 個英文字母。
- A～F 為固定標籤；姓名欄最多輸入 3 個字，不會把英文字母刪掉。
- A4 橫式列印排版。

本次修正：
- 修正「休假」31 個日期格在瀏覽器／列印時被拆成直排的跑版問題。
- 保持 table cell 本身為表格格子，僅在格子內部使用 grid 排上下輸入格。
