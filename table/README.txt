shift_roster_v1

獨立版排班表工具，不使用外部 CDN 或私人軍火庫。

主要功能：
- 依年份 / 月份自動生成 28～31 天
- 上方日期帶兩白兩灰，跨月份延續
- 六日粉紅底
- 週六休假預設禁休斜線，可逐日取消
- 23～07 的週六預設灰底，可逐日取消 / 補上
- 特殊模式可將單一排班格標成粉紅底
- 班別格每格只能輸入一個英文字母
- 點 07～15、15～23、16～24、23～07、00～08 班別標籤，可快速將整列填入同一個英文字母；之後每格仍可個別修改
- 本月清空：清除當月排班內容與手動標記，保留姓名、公休 / 特休數字，並恢復當月預設週六規則
- A～F 姓名與特休、公休統計連動
- A4 橫式列印，保留背景色
