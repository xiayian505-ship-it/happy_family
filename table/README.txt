shift_roster_v1

- 完全獨立版：只使用本地 HTML / CSS / JS，不呼叫軍火庫、CDN 或外部套件。
- 年／月可切換，自動產生當月 28～31 天。
- 上方日期列採兩白兩灰循環，跨月份連續。
- 星期六／日使用參考表的粉紅底。
- 五個班別每格限輸入一個英文字母。
- 休假列每天可輸入上下兩個英文字母；兩個輸入區之間不顯示橫線。
- 禁休模式：週六預設禁休斜線；按「禁休」可逐日加／取消，週六也可單獨取消。
- 特殊模式：按「特殊」後，可點任一排班格切換粉紅底，再點一次取消。
- 大夜模式：23～07 這列的週六預設灰底（參考 JPG 取樣約 #B7B7B7）；按「大夜」後可逐格取消或補上灰底。若同一格再用「特殊」標記，粉紅底優先顯示。
- A～F 為固定代號，姓名可輸入三個中文字，右側特休可輸入兩位數。
- 右側公休天數可輸入兩位數，並同步到底部統計。
- 列印為 A4 橫式，並要求瀏覽器保留日期底色、週末粉紅底、大夜灰底與特殊粉紅底。
