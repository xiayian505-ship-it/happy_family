shift_roster_v1｜櫃檯人員排班紀錄表

這是一份完全獨立的前端版本。
不呼叫軍火庫、不使用 CDN、不依賴外部套件；HTML / CSS / JS 放在同一資料夾即可使用。

檔案：
- shift_roster_v1.html：頁面骨架
- shift_roster_v1.css：畫面 / 手機自適應 / A4 橫式列印
- shift_roster_v1.js：排班輸入、模式、對話框、資料狀態
- shift_roster_rules.js：規則檢查（獨立本地 JS）
- shift_roster_export.js：原生 Canvas 繪製 → PNG → 預覽 / 下載 / 列印

目前主要功能：
1. 年月切換，自動生成日期與星期。
2. 日期列兩白兩灰跨月連續；六日粉紅。
3. 週六休假欄預設禁休斜線，可逐日取消。
4. 23~07 週六預設灰底，可設定一般大夜 22~06、特殊大夜時間或取消灰底。
5. 粉底：特殊班粉紅底 + 實際時間，下方長條以「A / 12 / │ / 20」直排註記。
6. 假別：公休、特休、請假、例外排休。
   - 請假代號顯示紅字。
   - 特休／請假會在下方長條顯示直式備註。
7. 開會：指定日期後，下方長條顯示「8 點 開 會」，不參與工時檢查。
8. 點班別標題可整列填 A~F，之後仍可逐格修改。
9. 點下方姓名區的 A~F 代號可開啟「批次排公休」：當月日期可複選，最少 1 天、最多 8 天；既有公休會預先勾選，特休／請假仍以單格方式處理。若某日休假兩格已有人，或該員工當日已排班，該日不覆蓋原資料，其他日期照常排入，完成後會列出未排入日期並回到班表單獨修改。
10. 排班與休假互斥；衝突時選「排班 / 休假」。
11. 禁假日輸入休假時，可選「例外排休 / 請假 / 返回」。
12. 人員班別：A~F 可複選早班／中班／夜班。早班＝07~15；中班＝15~23、16~00；夜班＝23~07、00~08。只有填入姓名的人員會進入規則檢查，F 可保留空白作預留欄。
13. 排假檢查：只計公休（含例外排休），特休／請假不計入每月公休目標。
14. 規則檢查（逐條提醒、可選例外安排）：
    - 禁假日排公休／特休
    - 有效員工未設定人員班別
    - 同組同日多人休假（日／晚班組與大夜組）
    - 中班休 → 隔天早班休的相鄰排休順序
    - 特殊班缺少有效實際時間
    - 連續上班超過 6 天
    - 轉班間隔低於 12 小時
15. 本月清空：保留姓名與公休／特休數字，其餘本月資料清掉。
16. 列印／匯出 PNG 前詢問是否加入右上角輸出時間。
17. PNG：原生 Canvas 直接繪製，不使用 DOM→SVG foreignObject、不呼叫第三方套件。
18. A4 橫式固定：@page A4 landscape，現階段安全邊界 6mm；列印內容區固定 285mm × 198mm。
19. 全部使用系統安全字體 fallback，不外連字體。

注意：
- 目前資料只存在本次網頁執行期間，重新整理會清空；尚未接資料庫 / localStorage。
- 未來若接資料庫，建議沿用目前資料邏輯再抽成獨立資料層。
- 規則提醒採「提醒、不硬鎖」方向，因為現場存在協調後的例外安排。

說明頁
- 畫面上方為「班表｜說明」分頁。
- 說明頁為螢幕用，不進 A4 列印與 PNG。
- 「班表輸入」整理年月、姓名、整列填入、休假、標記工具、檢查、JSON、清空與輸出方式。
- 「排假規則」只直接展示目前生效的基本值；其餘規則以大標題收合，需要時再展開。
- 可在「編輯基本值」調整每月公休、連續上班上限、轉班最低時數、一般大夜時間。
- 目前設定只保留在本次頁面；JSON 匯入／下載按鈕仍為預留，尚未接功能。
- JSON 說明包含 .json 副檔名、資料備份用途及整包程式搬移方式。
