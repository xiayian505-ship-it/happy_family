    這版的用途
    
      
    目前輸出的是「可餵給現行 v3 JSON 匯入器做測試」的完整備份格式。因為現行 JSON 匯入會整包覆蓋，所以這支測試 JSON 會補齊必要的 settings。
    
      
    正式接回班表時不應這樣做。正式 Excel 匯入應只取 monthData，呼叫 saveMonth() 更新該月；settings、其他月份、年度特殊日期與既有人員資料都保留。
