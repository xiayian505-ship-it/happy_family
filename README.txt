shift_roster_v1｜櫃檯人員排班紀錄表（規則重整壓測版）

檔案：
- sbs_roster.html：頁面骨架
- sbs_roster.css：畫面 / 手機自適應 / A4 橫式列印
- sbs_roster.js：排班輸入、人員資料、規則壓測入口、月份狀態
- sbs_roster_storage.js：localStorage、月份、人員 ID、JSON 資料格式
- sbs_roster_rules.js：獨立規則檢查
- sbs_roster_backup.js：JSON 備份 / 匯入
- sbs_roster_export.js：Canvas PNG / 列印
- sbs_roster_excel_export.js：目前月份 JSON snapshot → 同版 Excel 匯出

本版規則重點：
1. B～F 每人只能有一個固定班別：早班 / 中班 / 大夜。
2. A 為固定例外：可排早 / 中 / 大夜；固定班別、同組排休、早中排休順序、連勤、轉班等排班規則一律不檢查 A。
3. 整列排班依班別過濾候選人：只顯示該固定班別人員 + A；套用時若該員工當日已排休，或已在其他實際時間重疊的班別中，該日直接留白。
4. 公休正常目標 8 天；可有 7 天等例外，檢查只提醒確認。
5. 下方「公休：N」「特休：N」是本月實際排了幾天，不是額度上限。
6. 公休 / 特休 / 請假分開計算；特休與請假不補公休目標。
7. 禁休日排公休或特休會提醒，可視實際狀況作例外安排；主管當月休假日以紅斜線顯示並視為禁休。
8. 同日排休固定分組：早班 + 中班同組；大夜自己一組；每組同日最多休 1 人。A 排除。
9. 相鄰排休固定規則：中班人員某日休假，隔天早班人員不能休假。A 排除。
10. 同一人同一天不可同時排班與休假；另有規則檢查可抓匯入或手動造成的殘留衝突。
11. 連續上班上限預設 6 天，保留跨月銜接；A 排除。
12. 轉班最低休息預設 12 小時，使用實際粉 / 灰底時間，保留跨月銜接；A 排除。
13. 不另做「班別間隔 / 班別順序」規則；實際調班由主管決定。
14. 不做每日早 / 中 / 大夜固定人數硬檢查，因實務存在例外。
15. 紅斜線日若 A 出現在排班或排休，規則檢查只提示「A不可排」，保留人工例外確認。

特休：
- 「櫃檯人員資料」可直接輸入姓名、到職日與固定班別。特休平常依到職日／前月資料自動計算；另提供「本月特休校正（選填）」＋「套用校正」，可在任何月份重新對齊實際餘額。
- 沒有套用校正時，一般月份依「上月餘額 - 上月已用特休」自動帶入；套用校正後，本月以校正值為起點，後續月份再從該值正常扣除／結轉，下一個取得日仍照原本累加／重置流程。
- 人員資料會同時顯示「本月可用／已排特休／目前剩餘」；班表姓名旁的小數字只讀顯示本月月初可用值；當月排入的特休於下個月結轉時才扣除。
- 到職滿 6 個月觸發一次；之後每年到職週年觸發。
- 預設取得級距：6 個月 3 天、1 年 7 天、2 年 10 天、3～未滿5年 14 天、5～未滿10年 15 天、10 年 16 天，之後每年 +1，最高 30 天；可在「說明 → 編輯基本值」修改。
- 取得月份在人員資料選「累加特休」或「舊額歸零，換成本次天數」；依目前月結邏輯於次月套入餘額。
- 取得日的下方長條會顯示「人員代號 / 取得天數」事件，例如 D / 10。
- 主管使用同一套特休級距，再將應得天數 ÷ 2 並以 0.5 天進位；主管取得日下方長條以主管代號 / 折半後天數顯示，例如 L / 15。
- 特休檢查會抓：未設到職日、未設餘額、使用超過餘額、前月結轉數字不一致、取得日尚未選累加 / 重置。

壓測按鈕：
- 檢查公休天數
- 檢查禁休日
- 檢查同組撞休
- 檢查早中排休順序
- 檢查班休衝突
- 檢查特休
- 休假規則全部
- 檢查固定班別
- 檢查連勤 6 天
- 檢查轉班 12 小時
- 排班規則全部
- 完整規則檢查

測試期刻意把按鈕攤開；先求每條規則可單獨驗證，不處理介面收納與美化。

Excel 匯出：
- 「匯出 Excel」會先保存目前畫面，再直接在記憶體取得與「下載 JSON」相同結構的 snapshot，交給 Excel renderer 產生目前月份的 .xlsx。
- 中間 JSON 不會下載、不需重新上傳；使用者只會收到 Excel。
- Excel renderer 獨立放在 sbs_roster_excel_export.js；主程式與 JSON 備份邏輯不重複實作。
- 使用 ExcelJS 4.4.0 CDN；開啟頁面時需能載入該元件。

資料版本（本輪清理）：
- localStorage namespace：sbs_elitehotel:shift_roster:v3
- schemaVersion：3
- 備份 format：elitehotel-shift-roster-v3
- 不讀取、不轉換 v2 與更舊資料；舊 localStorage 即使仍存在也會被新版完全忽略。
- 已移除上一版遺留的「同日排休分組可切換／人數可調／相鄰排休開關／轉班開關」資料欄位；這些規則現在依定案內容固定。
- 已移除舊特休提醒旗標與舊夜班灰底 key 相容程式。

本輪「櫃檯人員資料」補強：
- 櫃檯人員資料可直接輸入姓名、到職日、固定班別；特休新增「本月特休校正（選填）」與「套用校正／取消校正」。
- 特休顯示「本月可用 / 已排特休 / 目前剩餘」；班表姓名旁的小數字改成只讀的本月月初可用值；當月使用量到下個月才反映扣除。
- 更換人員身分時，不沿用原槽位的特休起始值；若有同一 employee ID 的前月資料就自動銜接，沒有前月資料但有到職日則依年資自動建立起點；若隔一段時間才重新使用，可在當月再次套用校正。
- 特休以「自動計算為主、校正選填」：校正輸入本身不會改資料，必須按「套用校正」才生效；可在任何月份重複校正，按「取消校正」則回到系統依前月／到職日計算的值。
- 完成後再次掃描：未引用函式 0、只宣告未使用的頂層變數 0、HTML 孤兒 ID 0、CSS 無宿主 selector 0；printImage 為匯出列印時動態建立節點，非死碼。


本輪主管資料：
- 「櫃檯人員資料」下方新增「主管人員」：姓名、班表顯示字（限 1 字）、代號、到職日。
- 主管當月休假只記日期，不分假別；需要標假別時使用原本長條備註。
- 主管休假日休假欄斜線改紅；若同日原本也是一般禁休，紅線優先，取消主管休假後會回到原本黑線狀態。
- 本輪不新增任何主管排班專用欄位或功能。

年度特殊日期：
- 「進階資料管理 → 特殊日期設定」可一次設定指定年度 1～12 月的休假日／補班日。
- 休假日：日期改紅並預設黑色禁休斜線；補班日：即使原本是紅色日期，也改回一般黑字並取消預設禁休斜線。
- 11、12 月若下一年度尚未設定，班表上方會顯示提醒，可直接開啟下一年度全年設定。
- 年度特殊日期會跟 JSON 備份一起匯出／匯入。

Excel 匯出暫緩同步：
- sbs_roster_excel_export.js 本輪刻意不修改。
- 現有 Excel 匯出仍可使用目前既有欄位，但主管紅斜線、主管取得日等 v3 新視覺暫不補入 Excel，等班表需求穩定後再一次更新。
