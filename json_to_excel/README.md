# EliteHotel JSON → 同版 Excel｜目前班表專用版

這是獨立測試工具，**目前不接進正式班表**。

目標：讀取目前 `elitehotel-shift-roster-v3` / `schemaVersion: 3` 的完整班表備份 JSON，選擇月份後輸出可編輯的 `.xlsx`。

## 使用

1. 開啟 `json_roster_to_excel_v3.html`
2. 選擇正式班表「下載 JSON」產生的備份檔
3. 若 JSON 內有多個月份，選擇要匯出的月份
4. 按「匯出同版 Excel」

> 使用 ExcelJS 4.4.0 CDN，第一次開啟需有網路。

## 目前已同步

- 年月 +「櫃檯人員排班紀錄表」標題
- 日期列兩白兩灰，跨月份延續
- 週六／週日粉紅底
- 年度特殊日期：休假日紅字、補班日取消週末粉底
- 5 個班別 + 早／中／中／夜／夜
- 大夜週六灰底與手動 override
- 特殊班粉紅底
- 休假區兩格內容
- 一般禁休黑斜線
- 主管休假紅斜線（優先於一般禁休）
- A～F 姓名 + 本月月初特休數字
- 特殊時間、灰底時間、假別、開會、手動長條備註
- 櫃檯人員依到職日／特休級距顯示取得日事件
- 主管依到職日／特休級距折半進位後顯示取得日事件
- 下方日期列
- 每人公休／特休統計
- 右側直排「請每人先各排…」說明
- A4 橫式、單頁寬度列印設定

## 刻意不做

- 不修改 JSON
- 不寫回正式班表
- 不讀 localStorage
- 不接正式班表按鈕
- 不把 HTML 截圖塞進 Excel；輸出仍是真正可編輯的 Excel 儲存格

## 驗收重點

建議拿有以下資料的月份測：

- 週末與跨月兩白兩灰日期帶
- 年度休假日 / 補班日
- 主管休假日
- 特殊班粉底、夜班灰底與自訂時間
- 特休 / 請假 / 額外休假
- 櫃檯與主管的特休取得日
- 開會備註與手動備註

確認獨立工具輸出無誤後，再把同一份 renderer 接回正式班表。
